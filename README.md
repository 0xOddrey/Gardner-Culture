# Gardner Culture

Gardner Academy's staff culture and policy resources.

## Projects

- `gardner-culture` - the interactive Gardner Culture guide and original policy experience.
- `gardner-policies` - the standalone Next.js staff policy library, ready for Vercel.

## Local development

Run the culture guide:

```bash
cd gardner-culture
python3 -m http.server 4173
```

Run the policy library:

```bash
cd gardner-policies
npm install
npm run dev
```
